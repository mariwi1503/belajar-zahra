Cara Menambahkan Halaman / Bab Baru

Sistem portal sekarang telah dikelompokkan berdasarkan folder mata pelajaran. Dalam 1 folder pelajaran bisa memiliki banyak file HTML materi atau bab!

Langkah Menambah File Materi Baru:

  1. Buat file HTML baru di folder pelajaran terkait (contoh: matematika/pelajaran-5-pengukuran.html).
  2. Buka file index.html.
  3. Temukan mata pelajaran tersebut di dalam array studySubjects.
  4. Tambahkan satu objek baru ke dalam daftar chapters: [...], atur file: 'pelajaran-5-pengukuran.html' dan isAvailable: true.

Begitu disimpan, materi baru akan otomatis muncul di bawah mata pelajaran tersebut ketika diklik atau diperluas (expand)!
