Tentang Belajar Zahra

Selamat datang di Portal Belajar Zahra! Halaman utama ini dirancang khusus agar mudah diperluas (scalable) seiring bertambahnya bab dan mata pelajaran baru.

Cara Menambahkan Modul Baru ke Portal:

  1. Buat folder/file HTML bab baru (misal: matematika/penjumlahan.html).
  2. Buka file index.html.
  3. Tambahkan satu objek baru ke dalam variabel studyModules pada script di bawah.
  4. Atur status isAvailable: true dan arahkan tautan url. Selesai!

Sistem secara otomatis akan mengelompokkan kategori filter, pencarian langsung (live search), badge kelas, dan tombol akses.
